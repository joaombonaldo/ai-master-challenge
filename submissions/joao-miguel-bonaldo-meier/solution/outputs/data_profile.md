# Data Reality Check — Phase 0

Source: `data/raw/social_media_dataset.csv` (52,214 rows, 27 cols). Generated by
`solution/analysis/01_profile.py`.

## Shape & coverage
- 5 platforms, near-even split (10,296–10,598 rows each). No duplicates (row or content_id).
- Date range: 2023-05-29 to 2025-05-28. Key metric/flag columns (views, likes, shares,
  comments_count, follower_count, is_sponsored, disclosure_type, sponsor_category) have 0 nulls.
  Only free-text `hashtags` (8,743 null) and `comments_text` (8,688 null) have gaps.
- No `engagement_rate` column in raw data — must be derived.

## Sponsorship signal — REAL label, no proxy needed
- `is_sponsored`: 42.7% True (22,314) — balanced. `disclosure_type` is fully consistent
  ("none" iff not sponsored; else "explicit"/"implicit"). `sponsor_category` clean 6-way split.
  No creator-tier field exists; `follower_count` (uniform, 1,013–999,998) is the only size proxy.

## Engagement-rate formula check
- ER = (likes+shares+comments)/views: mean 0.199, **std only 0.0049**, range [0.179, 0.222] —
  essentially constant across all 52K rows regardless of the actual view/like counts.
- ER via /followers is wider (mean 0.014, std 0.061) but skewed by small-follower/high-view rows.
- Zero or near-zero (<0.1%) engagement share: **0.0%** — no dead posts, unlike real platforms.

## Distribution shape: unusually uniform, not heavy-tailed
- views 9,676–10,551 (skew 0.02), likes 1,354–1,668 (skew 0.03), shares 227–380, comments
  140–258, follower_count 1,013–999,998 (std 288K, evenly spread rather than concentrated).
- Social platforms typically show engagement/views spanning orders of magnitude with a few
  viral outliers; this dataset does not show that pattern in the current export.

## Segment spread — no signal anywhere
Median ER by group vs overall (0.19899), max/min ratio:
platform 1.0008, content_type 1.0008, category 1.0003, sponsored-vs-organic 1.0002,
follower quartile 1.0008. All <0.1% relative difference — noise, not signal.

## Verdict: WEAK-SIGNAL
Views/likes/follower_count show compressed ranges and near-zero skew; engagement rate is a
near-constant ~0.199 independent of platform, content type, category, sponsorship or creator
size; 0% dead posts; every segment cut differs by <0.1%. Categorical labels (platform,
sponsorship, category, disclosure) are internally consistent and usable for segmentation, but
the numeric engagement signal is extremely uniform, so any numeric "driver" claims must be
flagged as directional, not strong causal drivers.
