# Handoff 03 — Phase 3: Extra Tool (dashboard)

**Delivered:** dashboard/ (Next.js 15 + MUI, deployable to Vercel). Filterable dashboard over precomputed aggregates, now 8 filter dimensions (platform, category, creator-tier, sponsored, month, content_type, language, audience_location), all as uniform MUI Select dropdowns. Computed lift indicator + fair sponsored-vs-organic comparison (median of matched-group ratios, controlled by platform x category x creator-tier). Per-metric breakdown (like/share/comment rate per view, not just blended engagement rate) with a metric toggle on the platform chart. One "Gerar LLM Report" button producing an executive summary + prioritized, filter-aware recommendations (Groq free tier, openai/gpt-oss-120b, PT-BR), with rule-based/templated fallback if the API is unavailable. A "Gerar prompt de apresentação" button assembles (no LLM call) a ready-to-paste prompt for another AI tool to build a leadership PowerPoint from the current report. 13 commits so far, not yet pushed to origin as of this handoff.

**Agents used:** developer (sonnet) — ~20+ rounds across data layer, design iterations (G4-editorial → MUI migration), lift/fairness fix, rule-based → LLM recommendations (context/prompt overhaul), filter-aware format/duration/timing signals, new filters + per-metric breakdown, presentation-prompt feature, and many leader-driven UX fix passes. data-scientist (sonnet) — 1 ML feasibility spike (rejected a predictive model), 1 quick column-profiling spike (content_type/language/audience_location).

**AI got wrong / corrected (selected, see DECISIONS.md for full list):** (1) Initial sponsored-vs-organic comparison pooled data naively, violating GATE 0's fairness rule — fixed to a controlled, matched-group median. (2) Dashboard repeatedly leaked internal artifact names (findings.json, F-tags, "aggregate cells") into user-facing copy — scrubbed to read as a standalone product. (3) Chart colors inconsistently sourced from mismatched token objects — root-caused and unified. (4) LLM recommendations initially mislabeled a negligible 0.02pp gap as high-confidence — fixed with an explicit materiality floor. (5) Auto-fetching LLM calls on every filter change could silently hit Groq's rate limit and fall back invisibly — fixed via click-triggered generation. (6) Recommendations payload only ever saw a narrow slice (platform + one axis, gated behind "exactly one value selected") — rebuilt to always send a full ranked landscape across all axes. (7) The model was once caught doing its own (wrong) percentage subtraction, misreporting 0.032pp as 3.2pp — fixed by precomputing all diffs in code. (8) Format/duration/timing recommendations were dataset-wide instead of filter-aware — fixed with a server-only richer cube. (9) Platform chart bars had no visible value except on hover, so switching the metric toggle looked broken — fixed with on-bar labels.

**Leader decisions:** ML predictive model rejected (chance-level accuracy, honestly reported — solution/outputs/ml_feasibility.md); LangGraph rejected (plain function pipeline instead); Material UI adopted; dark mode removed entirely; all LLM-generated text in PT-BR; recommendations moved from rule-based to LLM-generated (rule-based kept as silent fallback); summary + recommendations merged into one click-triggered "Gerar LLM Report"; Tabs replaced with always-visible sections; content_type/language/audience_location added as real filters after profiling showed them independent and safe to expose (solution/outputs/dashboard_columns_profile.md); per-view metric rates (not just blended engagement rate) exposed since they can reveal reach-vs-virality differences the blended rate hides; all filters unified into one dropdown control pattern. All logged in process-log/DECISIONS.md.

**Open questions for next phase:** Phase 3e (formal QA pass + Vercel deploy) — qa-tester has not yet run a structured reproducibility/smoke-test pass on the dashboard, and it has not been deployed. Free-tier Groq rate limits are a known constraint for a live demo. Paid-model upgrade and Slack weekly briefing remain documented future steps, not built.
