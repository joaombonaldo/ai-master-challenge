# Handoff 03 — Phase 3: Extra Tool (dashboard, in progress)

**Delivered:** dashboard/ (Next.js 15 + MUI, deployable to Vercel). Filterable dashboard over precomputed aggregates (platform x category x creator-tier x sponsored x month); computed lift indicator + fair sponsored-vs-organic comparison (median of matched-group ratios, controlled by platform x category x creator-tier); LLM-generated executive summary + recommendations (Groq free tier, openai/gpt-oss-120b) behind one "Gerar LLM Report" button, PT-BR, with rule-based/templated fallback if the API is unavailable. 7 commits so far (dashboard skeleton through LLM report merge), not yet pushed to origin.

**Agents used:** developer (sonnet) — ~14 rounds across data layer, design iterations (G4-editorial then MUI migration), lift/fairness fix, rule-based then LLM recommendations, and multiple leader-driven UX fix passes. data-scientist (sonnet) — 1 ML feasibility spike (rejected a predictive model).

**AI got wrong / corrected:** (1) Initial sponsored-vs-organic comparison pooled data naively — the exact unfair comparison GATE 0 forbids — caught during a developer pass and fixed to a controlled, matched-group median. (2) Dashboard initially exposed internal artifact names (findings.json, F-tags, "aggregate cells," a "Methodology" panel) — leader caught this repeatedly; app is now scrubbed to read as a standalone product. (3) Chart colors were inconsistently sourced from different token objects across components (near-identical but not identical hex values) — looked like an unexplained bug to the leader; root-caused and unified. (4) LLM recommendations initially mislabeled a negligible 0.02pp gap as high-confidence and recommended acting on it — caught during live testing, fixed with an explicit materiality floor in the prompt. (5) Auto-fetching LLM calls on every filter change could silently hit Groq's rate limit and fall back without any visible sign — fixed by switching to click-triggered generation.

**Leader decisions:** ML predictive model rejected (R²=-0.00066, chance-level classification — see solution/outputs/ml_feasibility.md); LangGraph rejected for the pipeline (plain function composition instead); Material UI adopted over the custom-CSS "G4-editorial" design; dark mode removed entirely; all LLM-generated dashboard text in PT-BR; recommendations moved from rule-based to LLM-generated with rule-based as silent fallback; summary + recommendations merged into one click-triggered "Gerar LLM Report" action; Tabs replaced with 3 always-visible stacked sections. All logged in process-log/DECISIONS.md.

**Open questions for next phase:** Phase 3e (polish/QA/deploy) not started — qa-tester has not yet smoke-tested the dashboard end-to-end, and it has not been deployed to Vercel. Free-tier Groq rate limits are a known constraint for the live demo. Paid-model upgrade and Slack weekly briefing remain documented future steps, not built.
